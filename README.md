# 💼 Flow Money
Flow Money is a comprehensive personal finance manager designed to help users track their expenses, manage their budgets, and make informed financial decisions. This app provides a user-friendly interface for users to record their transactions, categorize their expenses, and set financial goals. With its robust features and intuitive design, the Budget App is an essential tool for anyone looking to take control of their finances.

## 🚀 Features
* Record and track transactions
* Categorize expenses and income
* Set financial goals and budgets
* Generate reports and charts to visualize spending
* Manage recurring transactions and subscriptions
* Integrate with currency exchange rates and calculate conversions
* Secure data storage using SQLite database
* User-friendly interface with Material Design

## 🛠️ Tech Stack
* Frontend: Flutter
* Backend: SQLite database
* APIs: Currency exchange rate API
* Packages: sqflite, path, cupertino_icons, fl_chart, intl, http, shared_preferences, share_plus, file_picker
* Platforms: Android, iOS

## 📦 Installation
To install the Budget App, follow these steps:
1. Clone the repository using `git clone`
2. Install the required dependencies using `flutter pub get`
3. Build and run the app using `flutter run`

## 💻 Usage
To use the Budget App, follow these steps:
1. Launch the app and create a new account or log in to an existing one
2. Record transactions by adding new entries or importing from a CSV file
3. Categorize expenses and income using the app's built-in categories or create custom ones
4. Set financial goals and budgets to track progress
5. Generate reports and charts to visualize spending and stay on top of finances
